# OneNote → Markdown 内容丢失矩阵（Loss Matrix）

> 记录 note2md 从 OneNote 迁移到 Markdown 时的**信息覆盖范围**与**已知丢失项**。
> 目的：迁移决策有据可查；后续实现按优先级逐项补齐，不靠记忆。
> 对应实现：`plugins/note2md/skills/note2md/tools/convert-xml2md.py`（转换）与 `export-onenote.ps1`（导出）。

## 一、当前覆盖范围（保住了什么）

转换脚本目前处理以下内容，迁移后**完整保留**：

| 内容类型 | 实现方式 | 备注 |
|----------|----------|------|
| 纯文本段落 | 收集 `<one:T>` 子树文本 | 支持换行 |
| 粗体 / 斜体 | OE 的 `bold` / `italic` 属性 → `**` / `*` / `***` | 仅这两种，其余样式不识别 |
| 标题（Heading） | `quickStyleIndex` / `style` 含 "heading" 启发式 → `#` 前缀 | 非精确，依赖 OneNote 样式属性 |
| 无序 / 有序列表 | `<one:List>` / `<one:Tag>` → `- ` | 有序列表也输出为 `-`（序号丢失） |
| 待办（To-do） | Tag index 0-3 → `- [ ]` / `- [x]` | 只识别未勾选/已勾选两种状态 |
| 表格 | `<one:Table>` → MD 表格 | 单元格内换行用 `<br>` 保留 |
| 笔记本→分区→页面层级 | 递归导出 + 递归转换 | 分区组（SectionGroup）在 4d59330 修复后保留 |
| 页面元数据 | `name` / `dateTime` → frontmatter（title/date/type/tags） | tags 恒为空，type 靠标题启发式 |

## 二、丢失内容清单

### A. 文本内容保住、但信息丢失

| # | 类型 | 丢失内容 | 迁移方案 | 优先级 |
|---|------|----------|----------|:---:|
| A1 | **超链接** | 全部 URL（链接文字还在，但点不动） | 解析 OE 的 link 属性 → `[text](url)`；`onenote://` 站内链接映射为相对路径 | 🔴 高 |
| A2 | **富文本样式** | 字号、颜色、高亮、下划线、删除线、字体 | MD 只支持粗/斜/删/行内码；颜色高亮可映射为 `<mark>`，其余**接受丢失** | 🟡 中 |
| A3 | **标签系统（Tag）** | OneNote 30+ 内置标签（重要⭐、待办优先、问题❓、灵感💡等）与自定义标签 | 非待办标签 → 行内图标或 frontmatter `tags`；当前仅 index 0-3 被识别 | 🟡 中 |
| A4 | **有序列表序号** | 数字序号（输出成了 `-`） | 从 `<one:List>` 读取起始序号 | 🟢 低 |

### B. OneNote 特有对象（MD 无对应物，需转资产）

| # | 类型 | 现状 | 迁移方案 | 优先级 |
|---|------|------|----------|:---:|
| B1 | **图片** | `_extract_images` 是占位符；且 Image 分支被顶部拦截丢弃（死代码） | 提取到 `assets/` + `![alt](assets/xxx)`。XML 里图片通常是嵌入 base64 或指向 OneNote 缓存，需实测 | 🔴 高 |
| B2 | **文件附件**（PDF/Word/Excel/zip 等） | 完全丢失 | 提取到 `assets/` + `[文件名](assets/xxx)`，与图片同机制 | 🟡 中 |
| B3 | **数学公式** | 纯文本提取会得到 MathML 乱码 | 转 LaTeX `$...$`（OneNote 存 MathML，需转换） | 🟡 中 |
| B4 | **手写墨迹（Ink）** | 笔画坐标流，文本提取为空 | 必须渲染为图片（打印/截图路径，依赖 Windows 端） | 🟢 低 |
| B5 | **绘图画布**（形状/箭头/流程图） | 同 Ink，纯文本丢失 | 渲染为图片 | 🟢 低 |
| B6 | **录音 / 视频** | 完全丢失 | 提取媒体文件到 `assets/` + MD 链接 | 🟢 低 |

### C. 结构 / 关系信息（转换后被"压扁"）

| # | 类型 | 丢失方式 | 迁移方案 | 优先级 |
|---|------|----------|----------|:---:|
| C1 | **子页面（SubPage）** | 页面层级拍平，子页变独立 md | 父页末尾生成 `[子页标题](子页.md)` 目录链接 | 🟡 中 |
| C2 | **页面间引用** | `onenote://` 链接全部失效 | 迁移时建立 页面名→md 相对路径 映射，重写链接 | 🟡 中 |
| C3 | **提醒 / 到期日** | 完全丢失 | 提取到 frontmatter（如 `due: 2026-08-10`） | 🟢 低 |
| C4 | **模板元数据** | 页面所属模板信息丢失 | 提取到 frontmatter `template:` | 🟢 低 |
| C5 | **单元格内非文本** | 表格 cell 里嵌的图片/附件/公式也会丢 | 依赖 B1/B2/B3 完成后，在表格分支内复用 | 🟡 中 |

## 三、优先级路线图

按「成本 / 收益」排序，建议实现顺序：

1. **A1 超链接 + C2 站内链接重写** — 纯文本解析，成本最低、收益最大（笔记里站内引用极多）
2. **B1 图片 + B2 附件** — 同一套 `assets/` 机制，先实测 XML 中图片的真实存储形式
3. **A3 标签系统** — 非待办标签进 frontmatter `tags`，同时解决「tags 恒为空」的缺陷
4. **C1 子页面目录** — 保住导航关系
5. **B3 公式、B4/B5 Ink/绘图、B6 媒体、C3 提醒、C4 模板、A2 样式、A4 序号** — 后置，按需补齐

## 四、决策记录

- **2026-08-04**：建立本矩阵。当前实现仅覆盖「文本 + 粗斜 + 标题 + 列表 + 待办 + 表格 + 层级」，图片/附件/链接/墨迹/公式等全部缺失。SKILL.md 中「No content is filtered」的描述**不准确**，需在实现补齐后修订，或先行改为明确声明覆盖范围。
- **B1 图片与 A1 链接** 是用户使用中感知最强的丢失项，列为最高优先级。
